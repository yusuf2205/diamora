# Diamoraa — что это и что сделано

*Состояние на 28.09.2026. English version: [PROJECT.en.md](PROJECT.en.md).*

Diamoraa — система для домашнего производства изделий из лент и бисера. Мастерицы шьют дома, сотрудники развозят материалы и забирают готовую работу, владелец видит всё: людей, склад, деньги, карту.

Всё работает на **собственном NAS владельца** (без облачных баз), наружу — через Cloudflare Tunnel:

| Адрес | Для кого |
|---|---|
| **diamoraa.uz** | мастерицы: скачать приложение или открыть веб-версию |
| **diamoraa.uz/w** | веб-версия для мастериц (iPhone и все, кто не ставит приложение) |
| **admin.diamoraa.uz** | панель сотрудников и владельца |
| **@diamora1_bot** | регистрация мастериц и вход через Telegram |

---

## Кто что делает

| Роль | Что может |
|---|---|
| **Главный администратор** | всё: люди, права, работы, склад, деньги, настройки, журнал; удалять и отменять |
| **Администратор** | по умолчанию почти всё, кроме управления ролями; права можно добавить или убрать |
| **Менеджер** | только **свои** мастерицы: их работы, выплаты, карта (сервер не показывает чужих) |
| **Мастерица** | своя работа, свои деньги, заказ работы, получение по QR |

Права проверяет **сервер**, а не экран: скрытая кнопка не даёт доступа.

## Как работает день

1. **Мастерица приходит.** Сама — через бота в Telegram (4 вопроса: имя, телефон, геолокация, залог) и ждёт одобрения. Или по **приглашению**: сотрудник вводит имя и телефон и отправляет ссылку с QR, мастерица открывает — и сразу в команде.
2. **Мастерица выбирает работу.** В каталоге «Наши работы» → «Заказать эту работу» (цвет, 9/18/27 м, пожелание). Сотрудник видит «Заявки на работу».
3. **Сотрудник готовит работу.** «Подготовить работу» (форма заполнена из заявки): материалы уходят со склада в комплект, печатается QR-этикетка.
4. **Двусторонняя передача по QR.** Сотрудник сканирует QR у мастерицы → «Начать передачу». Мастерица сканирует тот же QR своим телефоном, видит работу и материалы и **сама** нажимает «Подтвердить получение». Только тогда материалы числятся за ней. Есть «Есть проблема» (не хватает, не тот цвет…).
5. **Работа.** Мастерица отмечает прогресс («готово 12 из 18 м»), затем «Работа готова».
6. **Сотрудник забирает** («Забрал», по QR) и **принимает**: принято / брак / доработка. Деньги начисляются автоматически: **ставка за 9 м**, одна для всех, меняется главным администратором.
7. **Выплата наличными** — частично или полностью, с подтверждением; переплата невозможна.
8. **Отчёты и сводки**: день / неделя / месяц по мастерицам, выгрузка для Excel.

## Что сделано

### Для мастериц
- Android-приложение **Diamoraa** (Flutter) — скачивается с diamoraa.uz, **обновляется само**: скачивает новую версию в фоне и предлагает «Установить».
- **Веб-версия** diamoraa.uz/w с теми же функциями (вход через Telegram, QR-сканер камерой, получение, прогресс, заказ, деньги, уведомления) и кнопкой «Добавить на экран».
- Вход **без паролей** — через Telegram.
- Главная: «Выбрать работу» и «Сканировать QR» всегда вверху; ожидающая работа с оплатой и материалами; заявка; баланс; **заработки по месяцам**.
- **Уведомления в приложении** (колокольчик и уведомления Android, в том числе когда приложение закрыто): новая работа, «сотрудник у вас с комплектом», работу приняли, начислено, выплачено, заявка не принята, завтра и сегодня срок.

### Для сотрудников
- **Обзор**: быстрые действия в один ряд, «Требует внимания», счётчики (доставить, забрать, приёмка, к выплате, просрочено).
- **Мастерицы**: заявки на регистрацию, одобрение с залогом, карточка, менеджер, архив, **удаление** (если нет истории), **добавление по приглашению** (ссылка и QR прямо в Telegram).
- **Работы**: создание по шагам, передача по QR, приёмка, выплата, **отмена работы** (материалы на склад или в списание), **смена срока**, понятная история.
- **Карта** (Яндекс) с живыми точками; скрытие человека с карты — решает главный администратор; **«Маршрут» сразу строит путь от текущего места** в Яндекс Навигаторе.
- **Склад**: материалы, приход, списание, рецепты комплектов на 9 м, остатки у мастериц, предупреждение «заканчивается».
- **Печать QR-этикеток** (80×60 мм) для работ, мастериц и комплектов — из приложения и из панели.
- **Отчёты** с выгрузкой для Excel; **журнал действий**: кто, что, было → стало.
- **Команда**: добавить администратора или менеджера, роли, права по пунктам, пароли (только вручную), отключить, **удалить** (если нет истории).
- Уведомления: новая регистрация, заявка на работу, работа готова, проблема при передаче, просрочка, **материал заканчивается**, **итоги дня** (20:00), **отчёт за неделю или месяц**.

### Надёжность и данные
- Все денежные и складские действия идут **одной транзакцией**. Повтор или двойное нажатие не создают дублей: ключи идемпотентности, блокировки строк, уникальные индексы. База сама запрещает отрицательные остатки и правку истории.
- **Резервные копии** на NAS: ежедневный дамп, еженедельный базовый бэкап с журналом WAL, файлы, конфиг. Восстановление каждый день проверяется во временной базе.
- **Защита от сбоя NAS**: UGREEN после каждой перезагрузки сбрасывает владельца файлов в `/volume1/docker`. Служба `permfix` сама возвращает права базе и Redis за ~20 секунд. Выкладка проверяет права заранее и останавливается, ничего не меняя.
- Производительность на рост: постраничные списки, агрегаты в базе, индексы под отчёты и уведомления, история геопозиций хранится 90 дней, при большом системном шрифте экран остаётся компактным.

### Технологии
- **Сервер**: NestJS 11 + PostgreSQL 17 (Prisma) + Redis + MinIO + Socket.IO, бот Telegram — отдельный процесс.
- **Приложение**: Flutter 3 (Riverpod, GoRouter), шрифт Manrope, Яндекс MapKit, камера для QR, печать PDF.
- **Панель и веб-версия**: Next.js 16, React Query, Tailwind.
- **Инфраструктура**: Docker Compose на NAS, Caddy, Cloudflare Tunnel, скрипты выкладки и публикации APK.
- **Тесты**: API — 165+, приложение — 141+, веб — 62+; все прогоняются перед каждой выкладкой.

## Что осталось

- **iPhone-приложение**: нужен аккаунт Apple Developer (99 $/год) и Mac для сборки. Пока на iPhone работает веб-версия.
- **Мгновенные push-уведомления, когда приложение закрыто**: сейчас проверка идёт каждые ~15 минут. Для мгновенных нужен бесплатный проект Firebase на аккаунте владельца.
- **Карта в приложении**: если вместо карты квадраты — добавить `uz.diamoraa.app` в ключ MapKit на developer.tech.yandex.ru.
- Пилот: 1–2 дня с реальными мастерицами, затем правки по отзывам.
